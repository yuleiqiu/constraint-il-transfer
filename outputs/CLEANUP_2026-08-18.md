# Outputs cleanup audit — 2026-08-18

Scope: every first-level experiment directory under `outputs/` was reviewed.
The cleanup keeps canonical reports, formal state banks, correction datasets,
selected checkpoints, training configs/logs, and representative
visualizations. It removes artifacts superseded by a formal or merged result,
raw logs whose aggregate result is retained, duplicate renders, calibration
sweeps after parameter selection, rejected pilots, and empty directories.

## Removed

- `tabletop_guidance/`: 32 smoke/debug/duplicate result directories, two
  obsolete preliminary baseline JSON files, and seven non-selected or duplicate
  checkpoints. The exact checkpoint list is in
  `checkpoint_cleanup_candidates_2026-08-18.json`; this stage alone reclaimed
  28,200,406,044 bytes.
- `empty2d_guidance/`: four large per-step test JSONL files. The locked
  parameters, calibration records, aggregate test results, reports, 2x2 smooth
  ablation, videos, source dataset, and selected checkpoint remain.
- `gated_support_selector/`: the older absolute preflight and four-pair pilot,
  both superseded by the source-relative preflight and formal 20-pair gate.
- `guided_denoising/`: no-arrow duplicates of two visualization sets and the
  old `same_state`, `same_state_vector_field`, and
  `same_state_vector_field_v2` artifacts. Version 3 and the later LAN-O3DP
  closure artifacts remain; affected script defaults now point to version 3.
- `lan_o3dp_hand_off_guidance/`: calibration rollout directories and raw rho
  trajectory sweeps. The selected parameters, formal D0--D3 matrix, state
  bank, typical videos, calibration report, and a compact rho-sweep conclusion
  remain.
- `lan_o3dp_paper_aligned/`: D1 parameter-search directories and D2 partition
  directories for results that already have validated merged copies. The D2
  state bank, merged grids, contact-category checks, expanded-Q partitions,
  report, and representative videos remain.
- `persistent_correction_oracle/`: the superseded three-state pilot directory;
  the canonical 20-state result remains.
- `sample_refine/`: two superseded fixed-state sweeps; the final sweep and
  paired pilot remain.
- `targeted_finetuning/`: the superseded D1 development screen and rejected
  max-rotation pilot. Formal D1 evaluations, D2 checkpoint screens, support
  diagnostic, and verified C1 raw/paired HDF5 data remain.
- `task_constrained_guidance/`: predecessor state captures, feasibility
  calibrations, and repeat/margin variants. The strict 20-state banks, short
  continuations, full continuations, and Stage 1 report remain.
- `robomimic/train/`: two empty superseded low-resolution run roots, one
  rejected log-only run, and empty model/video/W&B temporary directories.
  No retained checkpoint was removed in this pass beyond the separately
  audited Tabletop checkpoint cleanup.

The non-Tabletop cleanup reclaimed approximately 190 MB. Together with the
Tabletop cleanup, the tree fell from roughly 46 GiB to 19.3 GiB. At completion,
`outputs/` occupies 20,737,782,488 bytes; 20,333,659,576 bytes are retained
model/training storage under `robomimic/`.

## Explicitly retained

- all seven checkpoints in `docs/checkpoint_retention.md`;
- `targeted_finetuning/c1/correction_raw.hdf5` and
  `targeted_finetuning/c1/correction_pairs.hdf5`;
- formal fixed-state banks used by paper-aligned, hand-off, Tabletop,
  task-constrained, support, branch-value, and persistent-correction results;
- all canonical conclusion documents and task-level aggregate summaries;
- representative videos listed by each stage's README or artifact index.

Deleted local ignored artifacts are not recoverable except by rerunning the
preserved configurations and code. Deleted tracked pilot summaries remain
recoverable from Git history.

## Final workspace closure — 2026-08-25

After rebuilding the new aggregates under `/tmp`, the final closure removed
570,070 additional bytes from these exact paths:

- 185,738 bytes:
  `tabletop_guidance/counterfactual_rescue_5scene_5noise/part_s1_s5/`,
  `part_s4/`, `part_s7/`, and `part_s8/`. The retained `merged/` rows, summary,
  report, and non-path manifest content match a fresh merge exactly. The raw
  partitions are recoverable only by rerunning the frozen evaluation contract.
- 7,270 bytes:
  `tabletop_guidance/baseline_epoch100_eval20_h600_seed26000.json`, superseded
  by the retained 50-episode result.
- 57,841 bytes:
  `tabletop_guidance/raised_milk_pair_seed819_ep0_q008_rho3/`, a
  non-canonical single-layout exploration superseded by the retained five-layout
  state bank and paired results.
- 219,451 bytes: the six rollout JSONL files in each of
  `empty2d_guidance/smooth_h400_circle/` and
  `empty2d_guidance/smooth_h600_circle/`. Both result aggregates were rebuilt
  from those rows with all metrics equal to within `1e-12` before deletion.
  They are reproducible from the retained contracts, epoch-100 checkpoint, and
  evaluation code.
- 99,770 bytes: root `wandb/`, `third_party/robosuite/.venv/`, and
  `third_party/robosuite/uv.lock`. These were disposable run metadata and an
  accidentally generated nested environment / lockfile.
