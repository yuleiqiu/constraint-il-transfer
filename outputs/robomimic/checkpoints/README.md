# Legacy Robomimic Checkpoints

This location formerly held externally copied image-action checkpoints used by
the 2026-06-22 masked / unmasked baseline launchers. They were superseded by
the executable delta-EEF epoch-260 source and deleted during the 2026-07-31
cleanup. Historical scripts and result summaries remain in Git, but the old
checkpoints must be regenerated or restored externally to rerun those exact
launchers.

Active local checkpoints are governed by `docs/checkpoint_retention.md` and
live under `outputs/robomimic/train/`.
